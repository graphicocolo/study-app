# Udemy JavaScript 練習＆講座　第二章 BMI計算アプリを作ろう

## 仕様

**UI要素**

- 身長入力欄
- 体重入力欄
- 実行ボタン
- BMI 表示

**BMIの計算式**

入力はcm、計算式はmなので注意

- BMI = 体重kg÷(身長m)<sup>2</sup>
- BMI = kg / (m * m)
- m = cm / 100

**UI**

TailwindCSS と Basecoat を使用
