# Udemy JavaScript 練習＆講座　第8章 ストップウォッチを作ろう リメイク

## 仕様

- 経過時間
  - 表示は 分・秒・ミリ秒（millisecond）
  - ミリ秒は上二桁を表示
  - maxは60分（1時間）まで
- スタートボタン
  - 初期（0秒）はボタンは有効
  - 計測中は `disabled` 属性を付与
  - 停止中はボタンは有効
  - 最大時間に達したとき `disabled` 属性を付与
- ストップボタン
  - 初期（0秒）は `disabled` 属性を付与
  - 計測中はボタンは有効
  - 停止中は `disabled` 属性を付与
  - 最大時間に達したとき `disabled` 属性を付与
- リセットボタン
  - 初期（0秒）は `disabled` 属性を付与
  - 計測中はボタンは有効（計測中にクリックで即リセット）
  - 停止中は有効
  - 最大時間に達したときは有効

### ボタンの状態設定

※計測中にリセットを押したときは「即リセット」<br>
リセット後はボタンは初期状態に戻る

|  状態  |  スタートボタン  |  ストップボタン  |  リセットボタン  |
| ---- | ---- | ---- | ---- |
|  初期（0秒）  |  有効  |  disabled  |  disabled  |
|  計測中  |  disabled  |  有効  |  有効  |
|  停止中  |  有効  |  disabled  |  有効  |
|  最大時間に達したとき  |  disabled  |  disabled  |  有効  |

### ミリ秒の更新間隔

ミリ秒を表示するなら setInterval を現在の1000msのままにはできません

何ms間隔で更新するか（10ms・100msなど）を決める必要があります

↓

**10ms** とする

#### 更新間隔と挙動

1分は60,000ミリ秒(1分 = 60秒 = 60 * 1,000)

ミリ秒の上2桁（センチ秒）を表示するなら **10ms** が適切。

| 更新間隔 | 挙動 |
|---------|------|
| 100ms | 0.1秒ごとに更新。ミリ秒の1桁目しか変わらず、上2桁がほぼ止まって見える |
| 10ms | 0.01秒ごとに更新。上2桁が自然に動く |
| 1ms | 更新が速すぎてブラウザの描画が追いつかず、実質10ms相当になる |

### 最大時間に達したときの挙動

自動停止する（ボタンの状態は、ボタンの状態設定の表の通り）

## 実装ステップ

1. 新たに秒の下のミリ秒表示欄を作成
2. ミリ秒を上2桁に切り捨てる処理を追加
3. `disabled` 属性を付与する関数を作成
```js
function setButtonState(state) {
  startButton.disabled = state === "measuring" || state === "maxTime";
  stopButton.disabled = state === "initial" || state === "stopped" || state === "maxTime";
  resetButton.disabled = state === "initial";
}
```
4. ボタン状態を初期設定値に追加

## 詰まった点

- 10秒を超えた時点で、ミリ秒と秒のカウントが同じになってしまう
- 各ボタン `disabled` の時に、押せないような見た目にしたい（cursor の pointer を外す）

### 10秒を超えた時点で、ミリ秒と秒のカウントが同じになってしまう

**原因：** `Math.log10` で桁数を数えて割る数を変える方法は、桁数が変わる瞬間（10000ms = 10秒）に割る数が `100` → `1000` に変わり、結果が秒と同じ値になる。

```js
// NG
const digit = Math.floor(Math.log10(diffMs)) + 1;
const millSeconds = Math.floor(diffMs / Math.pow(10, digit - 2));
// diffMs = 9999  → digit=4 → 9999 / 10^2 = 99  ← 正常
// diffMs = 10000 → digit=5 → 10000 / 10^3 = 10 ← 秒と同じになる
```

**ヒント：**「ミリ秒の上2桁」は「1秒未満の部分（0〜999ms）の上2桁」

- 1000ms = 1s
- `diffMs % 1000` で1秒未満の部分（0〜999）が取れる
- それを10で割ると上2桁（0〜99）になる
