## ヒント

### 経過時間を時・分・秒に変換する

```js
const diffMs = Date.now() - timeStart;
const totalSeconds = Math.floor(diffMs / 1000); // 経過時間をミリ秒から秒へ

// 時間を算出
const hours   = Math.floor(totalSeconds / 3600);
// 3600 = 60秒（1分）× 60分（1時間）で割ると1時間未満の秒数が算出
// さらにその秒数を60で割って分を出す
const minutes = Math.floor((totalSeconds % 3600) / 60);
const seconds = totalSeconds % 60;
```

- `%`（剰余演算子）は割り算の余りを返す

| totalSeconds | ÷60の商 | 余り（= seconds） |
|---|---|---|
| 45 | 0 | **45** |
| 60 | 1 | **0** |
| 75 | 1 | **15** |
| 130 | 2 | **10** |

75秒なら「1分15秒」の**15秒部分**だけが取り出せる。分や時間の分は `Math.floor` で先に取り除いているので、`%` で残った端数だけが秒の表示に使える。

- `minutes` は「3600で割った余り（1時間未満の秒数）をさらに60で割って分を出す」2段階の変換

### 1時間で止める

```js
if (totalSeconds >= 3600) {
  clearInterval(countUpId);
}
```

### 表示をゼロ埋めして 00:00:00 形式にする

```js
const pad = (n) => String(n).padStart(2, '0');
element.textContent = `${pad(hours)}:${pad(minutes)}:${pad(seconds)}`;
```

### ヒント：ストップ後の再スタートで時間がリセットされる問題

**なぜリセットされるのか？**

スタートボタンを押すたびに `timeStart = Date.now()` が実行されるため、  
「今この瞬間」が新しいゼロ地点になってしまう。  
ストップ前にどれだけ時間が経過していたかが失われる。

**解決の方向性**

「ストップした時点での経過ミリ秒数」を別の変数に保存しておき、  
次にスタートしたとき、その保存した時間ぶんだけ `timeStart` をさかのぼらせる。

```
再スタート時の timeStart = Date.now() - （ストップ時点で保存した経過ms）
```

こうすると、インターバル内の `Date.now() - timeStart` が、  
「前回の経過時間 + 今回の経過時間」の合計を正しく返すようになる。

**手順のヒント**

1. 経過ミリ秒数を保存する変数（例：`pausedElapsedMs`）を `0` で初期化しておく
2. ストップ時に `clearInterval` する前に、現時点の経過ms を `pausedElapsedMs` に保存する
3. スタート時に `timeStart = Date.now() - pausedElapsedMs` とする
4. リセット時は `pausedElapsedMs` も `0` に戻す
